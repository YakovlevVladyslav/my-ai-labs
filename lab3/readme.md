# Миграция животных — этап 5: эксперименты и статистика

Включает этапы 1–4: Boids, поиск пищи/воды, смену сезонов, хищников.

## Запуск на Windows (PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

`main.py` показывает анимацию в Matplotlib (600 шагов).

## Автоматические эксперименты

```powershell
.\.venv\Scripts\python.exe experiments.py
```

Будет проведено **8 экспериментов по 600 шагов**. Все запуски используют одинаковое исходное случайное зерно `seed=42`; в каждом эксперименте меняется только указанная группа параметров. Для изменения длительности и воспроизводимости:

```powershell
.\.venv\Scripts\python.exe experiments.py --steps 600 --seed 42 --output results
```

В `results/` сохраняются:
- `summary.csv` — усреднённые по 600 шагам показатели каждого запуска и набор изменённых параметров;
- `<experiment>_steps.csv` — показатели каждого шага;
- пять `.png` — графики показателей по времени, с легендой для всех запусков.

## Определения метрик

- **polarization**: модуль среднего *нормированного* вектора скорости всех животных; 1 — одинаковые направления, около 0 — направления компенсируются.
- **mean_nearest_distance**: среднее расстояние до ближайшего соседа, с учётом циклических границ. Чем меньше, тем плотнее локальная группа; само по себе не означает образование одной общей стаи.
- **threatened_fraction**: доля животных в радиусе хотя бы одного хищника (после шага).
- **animals_at_resources**: число попаданий животных в доступные ресурсные зоны; если животное находится сразу в нескольких, оно учитывается более одного раза.
- **mean_resource_fraction**: средний оставшийся запас четырёх ресурсов (0–1).
- **min_predator_distance**: минимальная за весь запуск дистанция между хищником и животным; при отсутствии хищников — пустое значение (NaN).

Метрики вычисляются по **состоянию после каждого шага**. Дистанции учитывают циклическое появление с противоположной стороны карты.

## Ограничения модели

- Модель упрощённая: нет размножения, смерти, энергетических затрат и физических столкновений.
- Сезонный перенос зон ресурсов реализуется дискретно, каждые `season_length` шагов.
- Один случайный seed даёт воспроизводимое сравнение, но **не** статистическую достоверность. Для более надёжных выводов запускайте несколько `--seed` и сравнивайте результаты.
- Скорость хищников и их количество могут сами менять случайную последовательность будущих состояний. Поэтому абсолютные значения показателей могут отличаться между сценариями не только из-за непосредственного эффекта одного параметра.

## Структура

`config.py` — настройки; `animal.py` — правила Boids; `resource.py` — еда, вода, сезоны; `predator.py` — угрозы; `simulation.py` — обновление мира; `visualization.py` — анимация; `metrics.py` — измерения; `experiments.py` — серии запусков и экспорт CSV/PNG; `main.py` — запуск анимации.
